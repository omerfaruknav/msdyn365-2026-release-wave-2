# What's new: Enhanced Financial Reporting

> This video covers the enhanced financial reporting features in 2026 release wave 2, grouped for authors, users and administrators. Authors get views and where-used data to find uncategorized accounts, plus fact boxes that show which G/L accounts a totaling filter includes. Two author features, a test preview and line defaulting for row and column definitions, are said to come later in a minor version of 29. Users get report packs, which run several reports into one PDF and can be scheduled to the report inbox. Administrators get automatic change log setup for financial report definitions and new APIs on the report inbox.
