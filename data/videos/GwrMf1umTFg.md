# What's new in Expense Agent: Project Handling

> This session covers what is new in Expense Agent for projects. Users can now pick projects on expenses in the web app, not only in Business Central. Admins turn on project tracking in the setup guide and choose between all projects or only assigned projects. Assignment is done with a new Assigned resources section on the project card, and optionally per project task. The demo shows an expense in the web app with a project and task, the result in the Business Central expense report with a preview posting, and how adding a resource to a second project makes it appear in the web app.
