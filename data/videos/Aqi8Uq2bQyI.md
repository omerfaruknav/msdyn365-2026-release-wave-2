# What's new in Page Scripting

> This short session covers what changed in the page scripting tool, which records and replays user actions in the web client, for example for user acceptance tests. In this release the tool moves from preview to generally available. To get there it was fully localized and given an accessibility, usability and look-and-feel pass. Two recording capabilities were added: multiple selection in grids and validation of the text in message and error dialogs. The speaker closes by noting that agents can now be used to try to generate and run these scripts.
