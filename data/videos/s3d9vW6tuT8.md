# What's new in Expense Agent: Use Travel Request

> This video shows the optional travel request feature (also called spend request) in the Expense Agent, demoed in the Business Central client. An employee asks for permission to spend, the manager approves, and the employee later creates an expense report that points to the travel request. The demo covers itemized request lines with foreign currency amounts, the approval info, and the link from posted general ledger entries back to the request for audit. It also explains how to budget in a foreign currency by updating the local currency amount. The speaker notes that the web app and phone app versions are not ready yet, and that the Expense Agent creates the expense report automatically.
