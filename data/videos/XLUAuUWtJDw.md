# What's new in Document Reporting: Word add-in

> This video covers the updated Word add-in for document reporting in the 2026 release wave 2. It walks through the new data picker with a built-in company information data set, and a table builder that can now edit existing tables. It then shows a set of reusable design blocks for body layouts (addresses, field groups, amounts, signatures, notes) and a Hide if control. The last part covers sample documents for theme authors, help for header and footer layout authors, and where to upload themes and layouts in Business Central.
