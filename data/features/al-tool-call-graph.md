# Call graph analysis (AL tool graph command)

> The AL .NET tool gets a graph command that builds a call graph across an extension and its dependencies. You or a coding agent can query it, for example to find who can call an internal procedure, where the public boundary is, or the path from a page action to a method. It is a static offline analysis, so output can be compared between versions.
