# Integer to big integer field change

> A field can change from integer to big integer while keeping existing rows, aimed at entries that run out of numbers. The compiler and AppSourceCop warn about implicit conversions and overflow, but the change is allowed without copying data.

## Caveats mentioned

- Changing the type does not update the places where the value is used, for example assigning it to an integer field
- Implicit conversion may overflow at runtime
- Dependent apps that have not changed to big integer can overflow at runtime
