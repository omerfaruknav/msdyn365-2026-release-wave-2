# Snapshot debugging MCP for agents

> Agents can target an environment and start a snapshot recording for the next matching session, capturing values and call stacks. The agent analyzes the results and can place better snap points and re-arm until the cause is found.

## Caveats mentioned

- No snapshot is run on the client, all work happens on the server
- The developer still has to judge what the evidence means
- If the first snapshot lacks information, the agent uses ALSP to find callers and sets snap points elsewhere, then repeats.
