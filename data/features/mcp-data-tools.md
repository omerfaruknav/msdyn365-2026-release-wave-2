# MCP data tools

> Four system tools (find tables, table relations, table schema, data query) let an LLM write AL queries that Business Central compiles and runs, with no APIs needed. Compiler errors return to the agent so it can correct itself.

## Caveats mentioned

- Access depends on the permissions the user already has on tables
- Result quality depends on how good the agent is at writing AL queries
- Only what can be expressed in an AL query works; unsupported or non-optimal queries will not work
- Queries in Business Central limit how much data can be returned and how long a query can run
- Agent only sometimes corrects itself (described as 'often times')
