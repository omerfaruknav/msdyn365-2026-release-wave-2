## Caveats mentioned

- AI is not much involved in the refund document
- Credit memos are not compatible with directed put-away and pick or other advanced warehouse scenarios, so use return orders there
- A return order with one positive and one negative line can still be posted as is
- The document may need to be reopened before moving negative lines

## Prerequisites mentioned

- Shop setting for process return as credit memo or return order
- Advanced warehouse customers should use return orders
