# Use Shopify order number

> A setting in order synchronization on the Shopify shop card lets sales orders and invoices use the Shopify order number as document number with a Shopify number series. The setting is inherited when an order is imported.

## Caveats mentioned

- Covered in more detail in release notes and another video
- Sales invoice and sales order documents must support manual numbers
- Orders imported before the toggle was activated keep the old number; unlink and mark the document as not processed, then create it again
- Shopify numbers look different in the sales order list, so review compatibility with Business Central numbers because sorting may be affected

## Prerequisites mentioned

- Manual numbers enabled on sales order and invoice number series
